# 🐍 Atividades do Curso — Python & Django

Repositório destinado ao armazenamento das atividades, exercícios e projetos desenvolvidos durante meus estudos de **Python e Django**.

O objetivo deste repositório é acompanhar minha evolução na programação, desde os fundamentos da linguagem Python até o desenvolvimento de aplicações web com Django.
