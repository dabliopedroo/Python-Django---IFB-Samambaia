# 🐍 Primeira Avaliação — Curso Python & Django

Primeira avaliação prática realizada durante o curso de **Python & Django**, com o desenvolvimento de um sistema simples que simula operações bancárias.

---

## 📝 Questão

Desenvolver um programa em **Python** que simule as operações básicas de um banco.

O programa deve apresentar um menu com as seguintes opções:

```text
========== BANCO ==========

1. Depositar
2. Sacar
3. Consultar Saldo
4. Sair

============================
```

### Requisitos

* 💰 O programa deve iniciar com um saldo de **R$ 200,00**.
* ➕ **Depositar:** solicitar um valor e adicioná-lo ao saldo.
* ➖ **Sacar:** solicitar um valor e subtraí-lo do saldo, desde que o valor seja menor ou igual ao saldo disponível.
* 💵 **Consultar Saldo:** exibir o saldo atual.
* 🚪 **Sair:** encerrar o programa.
* 🔄 O sistema deve continuar funcionando até que o usuário escolha a opção **Sair**.
* 🧩 O programa deve utilizar **funções** para organizar as operações.
* 📝 No início do código deve ser inserido o comentário:

```python
# ..= Avaliação1 =..
```

---

## ⚙️ Funcionamento

O programa inicia com um saldo de:

```text
R$ 200,00
```

O usuário pode realizar diversas operações durante a execução:

```text
1 → Depositar
2 → Sacar
3 → Consultar saldo
4 → Sair
```

Após cada operação, o sistema retorna ao menu principal, permitindo que novas operações sejam realizadas.

O programa só é encerrado quando a opção **4 — Sair** é selecionada.
