# 🐍 Lista de Exercícios — Python + Django

Repositório desenvolvido para praticar **Python** e **Django** através de uma sequência de exercícios práticos.

O projeto aborda conceitos fundamentais de programação e, progressivamente, introduz conceitos relacionados ao desenvolvimento web com Django.

## 🚀 Tecnologias

- Python
- Django
- HTML
- CSS
- Git
- GitHub

## 🎯 Objetivos

- Aprimorar a lógica de programação com Python
- Praticar estruturas de dados
- Trabalhar com funções, condicionais e laços
- Desenvolver pequenos sistemas
- Introduzir conceitos de desenvolvimento web com Django
- Praticar organização de projetos
- Utilizar Git e GitHub durante o desenvolvimento
