# 🚗 Exercício 01 — Custo de um Carro

## 📋 Descrição

Este exercício consiste em calcular o **custo final de um carro** a partir do seu custo de fábrica, considerando a porcentagem do distribuidor e os impostos.

## 🎯 Objetivo

Praticar conceitos básicos de Python, como:

- Entrada de dados
- Variáveis
- Operações matemáticas
- Porcentagens
- Saída de dados

## 🧮 Cálculo

O custo final do carro é calculado considerando:

```text
Custo final = Custo de fábrica + Distribuidor + Impostos
