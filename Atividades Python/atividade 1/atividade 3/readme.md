# 🌐 Questão 2 — Cálculo de Tempo de Download

Segunda questão da lista de exercícios do curso de **Python & Django**, com o objetivo de calcular o tempo aproximado necessário para realizar o download de um arquivo utilizando uma determinada velocidade de internet.

---

## 📝 Questão

Faça um programa que peça:

* 📁 O **tamanho de um arquivo para download**, em MB.
* 🌐 A **velocidade do link de Internet**, em Mbps.

Após receber os valores, o programa deve calcular e informar o **tempo aproximado de download do arquivo**, apresentado em **minutos**.

---

## ⚙️ Funcionamento

O programa solicita ao usuário as duas informações:

```text
Digite o tamanho do arquivo (MB):
Digite a velocidade da internet (Mbps):
```

Em seguida, realiza a conversão necessária entre **Megabytes (MB)** e **Megabits (Mb)** e calcula o tempo estimado para concluir o download.

Ao final, o programa apresenta o **tempo aproximado de download em minutos**.
