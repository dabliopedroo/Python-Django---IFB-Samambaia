# Questão 1 — Custo de um Carro Novo

## Descrição

Programa desenvolvido em Python para calcular o custo final de um carro novo a partir do seu custo de fábrica.

O cálculo considera:

* **12%** do custo de fábrica referente ao distribuidor;
* **30%** do custo de fábrica referente aos impostos;
* O custo final é a soma do custo de fábrica, do valor do distribuidor e dos impostos.

## Fórmula

```text
Custo ao consumidor = Custo de fábrica + (12% do custo de fábrica) + (30% do custo de fábrica)
```

## Funcionamento

O programa solicita ao usuário o custo de fábrica do carro e realiza os cálculos necessários para determinar o custo ao consumidor.
